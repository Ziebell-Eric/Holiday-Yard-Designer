# Holiday Yard Designer V22

Holiday Yard Designer is a browser-based Halloween and Christmas decoration planner with a cross-platform Electron desktop wrapper.

## Website
Open `website/index.html` directly or deploy the `website/` folder to Netlify, Cloudflare Pages, or Vercel. No server or Node.js is needed for the website.

## Desktop builds
- Windows: run `powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1` inside `desktop/`.
- macOS: run `bash setup-macos.sh` inside `desktop/`.
- Linux: run `bash setup-linux.sh` inside `desktop/`.

These scripts install project dependencies and build installers. Windows uses winget to attempt Node.js installation when missing; macOS uses Homebrew if available; Linux uses apt where available.

## GitHub Actions
Open **Actions → Build desktop installers → Run workflow**. Download installer artifacts from the completed workflow run.

## Notes
- Installer binaries are not checked in; they are generated by the workflow.
- Layouts are stored locally; use project export/import to move them.
- Unsigned desktop apps may trigger operating system warnings.
- Test installers before distributing widely.
